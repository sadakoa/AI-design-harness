# Example: support inbox

What `design-builder` produced for a made-up PRD: a support team's inbox where urgent requests kept getting missed. In a real project this folder would be `work/features/<date>-support-inbox/`.

Open `proposal.html` in a browser (clone the repo first; GitHub only shows the source). It has the research, three clickable mockups in `options/`, the recommendation and the spec. Add `?state=loading`, `?state=empty`, `?state=error` or `?state=done` to an option's URL to see the other states. `review.md` is the review it ran on its own recommendation.

The design system here still has its placeholder `(example)` content, and the proposal says so. With your own principles and words filled in, the reasoning gets sharper.

All names, companies and requests are made up.
