# PRD: Support inbox — triage list

**Users:** Support agents who handle 50–100 customer requests a day, on a desktop.

**Problem:** Today the list is sorted by date only, so urgent requests get missed.

**Goal:** Agents can start with what's urgent.

**Must show:** priority (high, medium, low), status (new, in progress, done), assignee, received time, customer, subject.

**Must support:**
- Assigning a request to someone
- Assigning several requests at once

**Out of scope:** the request detail page.
