# Support inbox: urgent requests first

**Who:** support agents handling 50–100 customer requests a day on a desktop.

**Problem:** the inbox is sorted by date only, so urgent requests get missed.

**Goal:** agents can start with what's urgent.

**Must show:** priority (high, medium, low), status (new, in progress, done), assignee, received time, customer and subject.

**Must support:** assigning a request to someone, including several requests at once.

**Out of scope:** the request detail page.
