# 部品の選び方

> 答える問い：どの部品を使うか。似た部品をどう使い分けるか

「選ぶ」ことだけを扱う。部品ごとの振る舞いは各部品の仕様（`components/<部品名>.md`）に書く。新しい部品の仕様は `_template.md` をコピーして書く。

## やりたいこと → 部品

<!-- 書き換える。迷いやすい組み合わせから書く。全部の部品を並べない -->

| やりたいこと | 使う部品 | 使わない部品 | 分かれ目 |
|---|---|---|---|
| （例）結果を一時的に知らせる | Toast | Alert | 読み飛ばしても困らないなら Toast、読ませたいなら Alert |
| （例）元に戻せない操作の前に確かめる | 確認ダイアログ | Toast | 取り消せないなら必ず確認する |
| （例）一覧の文脈を保ったまま詳細を見せる | Sheet（横から出る面） | 別ページ | 一覧と行き来するなら Sheet |
| （例）状態を示す | 文字＋アイコン | 色だけのバッジ | `rules.md` R-02 |
