# Helpline

The web app for Helpline, a help desk for small support teams. Agents answer customer requests that come in by email and chat; team leads watch the queue and hand out work.

No build step: open `pages/inbox.html` in a browser. Components are plain web components in `components/`, and the colors, type and spacing are CSS variables in `styles/tokens.css`.

## Pages

- `pages/inbox.html`: open requests, newest first
- `pages/request.html`: one request and its conversation
